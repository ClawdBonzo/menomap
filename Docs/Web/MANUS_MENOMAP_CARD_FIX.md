# Fix: the MenoMap card on /apps must open the MenoMap page

On `https://gwlabs.app/apps`, the MenoMap card (`<li id="app-menomap">`) links straight to the App Store and says "See it
on the App Store ↗". Every other app card opens that app's own page and says "View app →". MenoMap must work the same
way. Change nothing else on the site.

## 1. The card

Make the MenoMap card exactly like the Trough card next to it:

```html
<li id="app-menomap"><a class="card" href="/menomap.html" style="--glow:rgba(212, 85, 42, 0.4)"><img alt="MenoMap app icon" class="icon" decoding="async" height="60" loading="lazy" src="/icons/menomap.webp" width="60"/><span class="body"><span class="name">MenoMap</span><span class="tag">Log hot flashes in one tap and bring clear notes to your doctor.</span><span class="go">View app <span aria-hidden="true">→</span></span></span></a></li>
```

- `href="/menomap.html"`. No `target="_blank"` and no `rel="noopener"`.
- The label is `View app →`, not `See it on the App Store ↗`.
- It stays in the **Body & Looks** section, right after Trough.
- If the card is also generated by JavaScript or a data file, fix it there too, so the page source and the rendered page
  match.

The App Store links with `ct=gw-menomap` on `/menomap.html` and `ct=gw-clinicians` on `/menomap/clinicians` stay as they
are. The `gw-home-menomap` link is no longer used anywhere.

## 2. Structured data on /apps

In the `ItemList` JSON-LD on `/apps`, the MenoMap entry (position 10) is missing the two fields the other apps have. Add
them so it matches Trough:

```json
"downloadUrl": "https://apps.apple.com/app/id6817484445",
"offers": {"@type": "Offer", "price": "0", "priceCurrency": "USD"}
```

## Check before you report

```
curl -s https://gwlabs.app/apps | grep -o '<li id="app-menomap"><a class="card" href="[^"]*"'   # href="/menomap.html"
curl -s https://gwlabs.app/apps | grep -c 'See it on the App Store'                            # 0
curl -s https://gwlabs.app/apps | grep -o '"name": "MenoMap"[^}]*}[^}]*}'                     # includes downloadUrl and offers
```

In a browser, on desktop and at 390 px wide: click the MenoMap card on `/apps` and confirm it opens
`https://gwlabs.app/menomap.html` in the same tab. Report the three curl outputs and that check.
